

### Module responsibilities

- **Themes.lua** — preset palettes, theme order, and display names only.
- **ThemeEngine.lua** — owns `ThemeEngine.CurrentThemeName`, mutable `Theme`, `RuntimeDiagnostics`, `ThemeDebug`, `pathOf`, `debugTrace`, color-role registry/resolution, transitions, appearance styling, `applyThemePreset`, and shared UI helpers.
- **SystemPrompt.lua** — hidden system prompt and prompt builder.
- **Sandbox.lua** — sandbox, script library, and workspace inspector.
- **SettingsView.lua** — settings UI.
- **Markdown.lua** — Markdown and code rendering.
- **Messages.lua** — message/conversation UI.
- **AIRequest.lua** — AI HTTP request and tool loop.

### Key behavior and features

- `saveSettings` is forward-declared before `ThemeEngine` and assigned later; `loadSettings` sets `ThemeEngine.CurrentThemeName` and calls `applyThemePreset`.
- Settings are split into **AI Settings** and **Theme Settings** tabs, each independently scrollable.
- Appearance has independent **Simple** and **Advanced** modes, both off by default. Simple applies restrained glass; Advanced exposes glass/gradient toggles, transparency, gloss, gradient direction/strength, and HSV start/end pickers. Theme preferences persist.
- Added **Red** and **Cursor Black** theme presets.
- Theme updates include dynamically recolored descendants; warnings only appear for registered roles missing from a preset. Large theme changes use a lightweight transition overlay, small changes use per-property interpolation, and the overlay is explicitly hidden after switching.
- Window dragging preserves scale-based position, applies pointer deltas, and snaps to the final target on release.
